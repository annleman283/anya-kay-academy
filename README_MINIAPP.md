# ANYA KAY Academy — Telegram Mini App v0.1

Рабочая первая версия интерфейса Mini App, адаптированная под существующую SQLite-базу образовательного бота.

## Уже реализовано
- Telegram WebApp initData авторизация (HMAC validation)
- Главная с реальным прогрессом из `students.current_lesson_order`
- Все уроки из существующей таблицы `lessons`, блокировка будущих уроков
- Экран урока, Telegram `file_id` видео/изображений через Bot API
- Материалы урока и бонусные материалы
- Тесты из существующей таблицы `questions`
- Сохранение попыток в существующие `attempts` + `answers`
- Разблокировка следующего урока в той же таблице `students`
- Разбор ошибок
- «Мои ошибки» на основе истории `answers`
- Новые заметки и закладки (две дополнительные таблицы; старые данные не затрагиваются)
- Профиль и финальный экран
- Визуальный стиль ANYA KAY: ivory / burgundy / champagne gold

## Важно
Эта версия не переносит и не дублирует уроки вручную: она читает существующую `lessons.db`. На Railway укажите тот же `DB_PATH`, который использует бот.

Текущие видео/файлы у бота хранятся в Telegram как `file_id`. Mini App умеет получать для них временный путь через Bot API. Для больших видео-ссылок используются существующие `video_url`.

## Переменные
- `BOT_TOKEN` — токен текущего образовательного бота
- `DB_PATH=/data/lessons.db` — тот же Volume, что у текущего бота
- `PASS_THRESHOLD=1.0`
- `PORT` — Railway задаёт автоматически
- `DEV_USER_ID` — только для локального preview, в production не нужен

## Локальный preview
Если рядом нет реальной базы, интерфейс покажет демонстрационные 16 уроков. Для сохранения прогресса нужен реальный Telegram user id / initData.

`python academy_server.py`

Открыть: `http://localhost:8080`

## Подключение в Telegram
После деплоя HTTPS URL Mini App нужно добавить через BotFather как Web App/Menu Button. В существующем боте кнопку «Открыть обучение» следует сделать `WebAppInfo(url=...)`.
