# Бот "Курс по наращиванию ресниц" — школа Ани К

Telegram-бот для обучения: ученицы смотрят видео-урок, проходят тест —
и только после правильного прохождения открывается следующий урок.
Для вас как администратора — всё управление кнопками, без единой команды вручную.

## Как это работает для ученицы

- Пишет боту `/start` → получает приветствие тремя сообщениями (с небольшой паузой) и
  постоянное меню внизу экрана: 📚 Все уроки / 📊 Мой прогресс / 🎁 Мои гайды / ℹ️ Помощь.
- Смотрит видео (или переходит по ссылке, если урок с YouTube-видео) + получает прикреплённые
  файлы-пособия, если вы их добавили.
- Жмёт «Начать тест» → вопросы и варианты ответов каждый раз в случайном порядке.
- После каждого ответа сразу видно, верно ли, и пояснение (если вы его написали).
- Все ответы верны → открывается следующий урок. Последний урок → тёплое персональное
  поздравление вместо обычного сообщения.
- Есть ошибки → можно пересмотреть видео или сразу попробовать тест снова — попыток
  неограниченное количество.
- «📚 Все уроки» — список всех уроков кнопками, можно в один клик вернуться к любому
  пройденному или текущему, не листая переписку.
- «🎁 Мои гайды» — бонусные материалы, откроются только после прохождения всей теории.
- Если не заходила 3+ дня и не закончила курс — бот сам напомнит вернуться к обучению.

## Как это работает для вас (администратора)

Всё через постоянное меню внизу экрана — печатать команды не нужно:

- **➕ Добавить урок** — название → описание → видео (файлом до 50 МБ или ссылкой) →
  файлы-пособия (по желанию, можно несколько) → вопросы теста (варианты и правильный
  ответ — кнопками, не нужно печатать номер) → пояснение к ответу.
- **📚 Мои уроки** — список уроков, у каждого: 👁 Предпросмотр (посмотреть, как видит
  ученица), 🎬 Заменить видео, ✏️ Название/описание, 📎 Файлы урока, 🗑 Удалить
  (с подтверждением).
- **🎁 Гайды** — добавить или удалить бонусные материалы-подарки, которые ученицы
  получают после завершения теории.
- **👩‍🎓 Ученицы** — список с прогрессом и кнопкой «Ответы: Имя» — все ответы каждой
  ученицы на каждый вопрос каждой попытки.
- **💾 Резервная копия** — присылает вам файл базы данных на компьютер (сохраните на
  всякий случай, если планируете вносить изменения).
- **🔄 Проверить как ученица** — сбрасывает ваш собственный тестовый прогресс и
  показывает курс так, как его видит ученица. Ваши тестовые прохождения никогда не
  попадают в статистику `/students`, эта кнопка полностью безопасна для реальных данных.

## Шаг 1. Создать бота в Telegram

1. Напишите в Telegram боту **@BotFather**.
2. Отправьте `/newbot`, придумайте имя и username (должен заканчиваться на `bot`).
3. BotFather пришлёт вам **токен** вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`.
   Сохраните его — это `BOT_TOKEN`.

## Шаг 2. Узнать свой Telegram user_id

1. Напишите боту **@userinfobot**.
2. Он пришлёт ваш `id` (число) — это ваш `ADMIN_IDS`.
   Если админов несколько — перечислите id через запятую: `111111,222222`.

## Шаг 3. Хостинг — Railway.app

1. Зарегистрируйтесь на **https://railway.app** (проще всего через GitHub-аккаунт).
2. Загрузите папку с ботом (`lash_bot`) к себе на GitHub в новый репозиторий —
   на github.com нажмите "New repository", затем "Upload files" и перетащите все файлы.
3. В Railway: **New Project → Deploy from GitHub repo** → выберите ваш репозиторий.
4. Railway сам увидит `requirements.txt` и установит зависимости.
5. Вкладка **Variables** → добавьте:
   - `BOT_TOKEN` = токен из BotFather
   - `ADMIN_IDS` = ваш user_id
6. **Settings → Deploy → Start Command**: `python main.py`
7. **Settings → Volumes** → создайте том, путь `/data` (тут будут храниться база данных
   и файл сохранения прогресса — чтобы ничего не терялось при перезапусках). Добавьте
   переменные:
   - `DB_PATH=/data/lessons.db`
   - `PERSISTENCE_PATH=/data/bot_persistence.pickle`
8. Нажмите Deploy. В логах должно появиться «Бот запущен, ожидаю сообщения...».

Ссылка на вашего бота для учениц: `https://t.me/username_вашего_бота` (username вы
придумали в Шаге 1 у BotFather).

## Шаг 3 (альтернатива). Свой VPS

```bash
sudo apt update && sudo apt install -y python3-pip python3-venv git
git clone <ссылка на ваш репозиторий> lash_bot
cd lash_bot
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

export BOT_TOKEN="ваш_токен"
export ADMIN_IDS="ваш_id"
export DB_PATH="/root/lash_bot/data/lessons.db"
export PERSISTENCE_PATH="/root/lash_bot/data/bot_persistence.pickle"
mkdir -p /root/lash_bot/data

python main.py
```

Для постоянной работы — systemd-сервис:

```bash
sudo nano /etc/systemd/system/lashbot.service
```

```ini
[Unit]
Description=Lash Extension Course Bot
After=network.target

[Service]
WorkingDirectory=/root/lash_bot
Environment="BOT_TOKEN=ваш_токен"
Environment="ADMIN_IDS=ваш_id"
Environment="DB_PATH=/root/lash_bot/data/lessons.db"
Environment="PERSISTENCE_PATH=/root/lash_bot/data/bot_persistence.pickle"
ExecStart=/root/lash_bot/venv/bin/python main.py
Restart=always

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable lashbot
sudo systemctl start lashbot
sudo systemctl status lashbot
```

## Технические детали

- База данных — SQLite (`lessons.db`), файлы (видео/пособия/гайды) хранятся не в базе,
  а в самом Telegram — бот сохраняет только `file_id`, так что база остаётся маленькой.
- **Ограничение Telegram**: файл, загружаемый ботом напрямую, не может весить больше
  50 МБ. Для более длинных/тяжёлых видео используйте вариант «Ссылкой» при добавлении
  урока (например, unlisted-видео на YouTube).
- Порог прохождения теста — 100% правильных ответов по умолчанию (переменная
  `PASS_THRESHOLD`, например `0.8` = 80%).
- Напоминания неактивным — раз в сутки, порог неактивности задаётся `REMINDER_INACTIVE_DAYS`
  (по умолчанию 3 дня).
- Вопросы и варианты ответов перемешиваются случайно при каждой попытке теста.
- Прогресс прохождения теста сохраняется на диск (`PERSISTENCE_PATH`), поэтому даже если
  сервер перезапустится посреди теста, у ученицы ничего не потеряется.
- Обновление кода в будущем: база данных и файл прогресса лежат отдельно от кода (в Volume),
  поэтому загрузка новой версии файлов на GitHub никак их не затронет.

Если что-то понадобится доработать — просто напишите, что изменить.
