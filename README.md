# ANYA KAY Academy v1.1

Исправления этой версии:
- исправлена реальная причина вечной загрузки на мобильном: синтаксическая ошибка в JS блока материалов;
- убраны конструкции, которые могут ломаться в старых мобильных WebView;
- обновлён cache-busting app.js/app.css;
- добавлен аварийный экран вместо бесконечного loader;
- «Знакомство» отображается как Урок 0 и не входит в основной счёт;
- «Ожог. Аллергия. Здоровье мастера» — один общий урок в структуре Academy;
- при первом входе реальной ученицы через Telegram приложение просит имя + фамилию латиницей для сертификата;
- имя сохраняется в `academy_profiles` по Telegram user_id и используется в профиле и сертификате;
- в обычном браузере сохраняется preview-режим без записи в рабочую БД.

## Безопасность старого бота
Не заменять текущий сервис Telegram-бота этим архивом. Academy разворачивается отдельным Railway Service.
До окончательной миграции используйте копию `lessons.db`, а не перезаписывайте рабочую базу старого бота.

## Railway
Start command: `python academy_server.py`
Healthcheck: `/health`
Variables: `BOT_TOKEN`, `DB_PATH`, `PASS_THRESHOLD`, `ADMIN_IDS`, optional `DEV_USER_ID`.
