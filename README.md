# ANYA KAY Academy Mini App — FINAL candidate

## Что уже реализовано
- Урок «Знакомство» отображается как **Урок 0** и не входит в счёт пронумерованных уроков.
- Главная, прогресс, продолжение обучения.
- Последовательная блокировка уроков по существующему `current_lesson_order`.
- Экран урока, видео Telegram/file_id или ссылка, материалы урока.
- Тест: вопрос за вопросом, мгновенная проверка, объяснение, итог, повторные попытки.
- «Мои ошибки», аналитика по урокам/темам.
- Избранное и личные заметки.
- Библиотека бонусных материалов.
- Финальный экзамен до 40 вопросов по всему курсу и экран THEORY COMPLETED.
- Telegram WebApp authentication; в обычном браузере безопасный preview.
- Мобильный splash имеет timeout/fallback и не должен зависать бесконечно.
- Railway healthcheck `/health`.

## Важно о существующем боте
Этот архив НЕ заменяет действующий Telegram-бот. Для сохранения реальных уроков, тестов и прогресса Mini App должен получить доступ к **той же реальной базе `lessons.db`**, которую использует бот. Не создавайте пустую базу поверх рабочей.

Сначала разверните Mini App отдельным Railway service. До подключения рабочей БД он показывает preview. После проверки интерфейса подключается копия/общая БД по безопасному плану. `BOT_TOKEN` нужен для Telegram auth и открытия Telegram-hosted media.

## Railway
Start command: `python academy_server.py`
Healthcheck: `/health`
Variables used: `BOT_TOKEN`, `DB_PATH`, `PASS_THRESHOLD`, `ADMIN_IDS`, optional `DEV_USER_ID`.
